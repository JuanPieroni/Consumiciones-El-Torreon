# Reglas de Programación para Amazon Q

## Análisis de Código
- SIEMPRE lee y analiza el código existente antes de hacer cambios
- Mantén la consistencia con el estilo de código actual del proyecto
- Respeta la arquitectura y patrones existentes

## Modificaciones de Archivos
- NO elimines código del usuario sin permiso explícito
- Modifica archivos completos de una vez, no en pequeños incrementos
- Lee las secciones que vas a editar antes de modificarlas

## Implementación
- Código mínimo y funcional, sin verbosidad innecesaria
- Incluye imports, dependencias y configuraciones necesarias
- Asegúrate de que el código sea sintácticamente correcto
- NO agregues tests automáticamente a menos que se solicite

## Validación
- Ejecuta y valida el código cuando sea posible
- Confirma que la solución resuelve el problema real
- Proporciona 1-3 enfoques de implementación antes del código

## Comunicación
- Explica QUÉ archivos modificarás y POR QUÉ antes de hacerlo
- Sé directo y conciso en las respuestas
- Usa el mismo idioma que el usuario
