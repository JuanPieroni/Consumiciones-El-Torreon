# Reglas de Consulta Obligatoria

## Consulta Antes de Actuar
- SIEMPRE pregunta antes de hacer cambios grandes
- Si hay más de 3 archivos a modificar, consulta primero
- Explica el plan ANTES de ejecutar cualquier cambio

## Definición de Cambios Grandes
- Modificar más de 50 líneas de código
- Crear más de 2 archivos nuevos
- Cambiar arquitectura o estructura del proyecto
- Eliminar o renombrar archivos existentes
- Modificar configuraciones importantes (vite, package.json, etc.)

## Proceso de Consulta
1. Analizar el problema/requerimiento
2. Proponer 2-3 enfoques diferentes
3. Explicar pros/contras de cada enfoque
4. ESPERAR confirmación del usuario
5. Solo entonces proceder con la implementación

## Excepciones (No requieren consulta)
- Fixes de bugs menores (1-2 líneas)
- Agregar imports faltantes
- Correcciones de sintaxis
- Cambios cosméticos menores

## Comunicación
- Ser claro sobre QUÉ se va a cambiar
- Explicar POR QUÉ es necesario el cambio
- Mostrar el impacto en el proyecto
